# Sacred Curator — Complete Color Token Reference

## Primary (Gold)
| Token | Value | Usage |
|-------|-------|-------|
| primary | #785600 | Text, icons, borders |
| primaryBrand | #B8860B | Gold highlights, gradients |
| primaryContainer | #986d00 | Gradient endpoints for CTAs |
| primaryFixedDim | #F5E6C8 | Active background states |
| primaryLight | #FBF3E0 | Badge fills, tinted surfaces |
| onPrimary | #FFFFFF | Text on primary backgrounds |
